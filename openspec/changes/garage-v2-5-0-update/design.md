# Design

## Context

`garage/templates/_helpers.tpl` builds `garage.toml` from `values.yaml`; a large
`garageTomlString` / `existingConfigMap` escape hatch already exists for anything
not modelled. New Garage parameters therefore only need values when the chart
claims to manage them.

`GARAGE_LOG_FORMAT` is a process env var, not a config file key, so it belongs in
the workload template's `env` list rather than `garage.toml`.

## Decisions

- **Empty defaults.** `publicEndpoint`, `publicEndpointPathStyle` and `logFormat`
  default to `""` and render nothing, so existing releases produce byte-identical
  manifests after the upgrade (no rollout on the config checksum).
- **Boolean handling for `public_endpoint_path_style`.** The value may arrive as a
  YAML boolean (`values.yaml`) or as a string (`--set`). It is printed raw so both
  forms yield a valid TOML boolean, and the gate uses `toString` so an explicit
  `false` is still rendered (a plain `if` would drop it).
- **Dashboard panels follow this chart's export.** The upstream panels use
  `${datasource}` / `job="garage"` / `{{instance}}`; the bundled dashboard uses a
  `$datasource` datasource variable and a `$Job` selector, so the ported panels use
  those to stay consistent with the other ten.
- **No admin API service.** Upstream's new optional admin service is redundant
  here: the chart's main Service already exposes the admin port 3903.
- **Docs live in the chart README.** `garage/README.md` is regenerated by
  helm-docs, so hand edits there are lost. The disclaimer and migration notes are
  kept in `garage/README.md.gotmpl` (excluded from the packaged chart) and the
  root README only links to `garage/README.md#migration-notes`.
- **Release step runs after chart-releaser.** The migration notes are extracted
  from the rendered chart README with `awk` and appended to the body that GitHub
  generated, guarded by a substring check so re-runs do not duplicate the section.

## Risks

- `public_endpoint` must be a full URI with a scheme; the chart does not validate
  it, matching Garage's own behaviour for other free-form values.
- Upgrades across v2.5.0 are one-way per node (upstream constraint), which is
  documented in the release notes rather than enforced by the chart.
